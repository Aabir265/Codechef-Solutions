## Problem Statement

<div class="_problemStatementWrapper_bh3c4_33" bis_skin_checked="1"><div class="_problemBodyContent_bh3c4_71" bis_skin_checked="1"><h3 class="notranslate">PostOrder Traversal</h3><p>Post-order traversal involves visiting the left subtree first, then the right subtree, and finally the root node. This method is useful for deleting the tree and freeing up the space, as it ensures that child nodes are processed before their respective parent nodes.</p>
<p><strong>Algorithm</strong>:</p>
<ul>
<li>Recursively traverse the left subtree.</li>
<li>Recursively traverse the right subtree.</li>
<li>Visit the root node and print it.</li>
</ul>
<p>For example, check the postorder traversal of the following binary tree.</p>
<p><img src="https://cdn.codechef.com/images/learning/graphs-trees/postorder-traversal.gif" alt="Postorder traversal"></p>
<h3>Task</h3>
<p>Given a binary tree, print its nodes in postorder traversal.</p>
